# XianyuScheduler V4.19

Android Root 闲鱼任务自动化助手。

## V4.19：麻将对子视觉求解

在 V4.18 水果视觉游戏基础上，本版开始自动处理“去点点消不停玩1关”。

流程：

`任务面板 → 点点消不停 → MAHJONG_PAIR_GAME → 截图 → 定位6x6棋盘 → 识别重复牌 → 相邻对子点击 / 非相邻同牌滑动靠近 → 截图验证 → 清关 → 返回任务面板`

安全原则：

- 只操作高置信度同牌。
- 教程水平相邻对子优先。
- 优先直线空路径滑动；自由拖动只是验证式兜底。
- 每个动作后重新截图，失败动作不重复盲试。
- 连续异常立即安全停止，不把任务误标成功。
- 人工触摸仍然立即接管并终止自动操作。

V4.18水果求解器、V4.17导航修复、V4.16任务面板快速衔接、V4.13学习库均继续保留。

直接覆盖安装，勿卸载或清除应用数据，否则学习库会丢失。
