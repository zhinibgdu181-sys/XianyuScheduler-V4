# V4.42.0 恢复与防误退版

本版在 V4.41.0 稳定栈式二消基础上增加恢复状态，解决单帧截图、OCR、动画或无动作导致提前退出的问题。

- 截图/OCR/暂时不稳定的槽位最多恢复三次，重新确认水果页、剩余数和槽位后继续。
- 连续无安全动作时等待 300–500ms 并重新截图，最多重试三次；低检测数量仍保存诊断图。
- 每次点击保留原动画等待；第一轮槽位验证或剩余数验证失败后再等待并进行第二轮验证，期间不重复点击。
- CLEAN/DIRTY 安全停止后检查实际页面，仍在水果页时最多重新运行一次 Solver；再次停止后保留现场。页面不明也禁止 BACK/重启。
- 识别算法、HSV/直方图阈值、三槽 LIFO、A+A / A+B 和槽优先规则保持不变。决策搜索留待 V4.43。

# XianyuScheduler

当前版本：**V4.42.0**

Android ROOT 辅助自动任务工具。当前界面按功能划分为四个底部入口：

- **首页**：ROOT / 闹钟权限、运行状态、功能说明。
- **今日**：查看当天已经验证完成的闲鱼任务。
- **自动化**：立即运行、停止、每日定时、真人学习模式。
- **日志**：查看并清理运行日志。

小游戏策略采用对象白名单：水果游戏只允许点击水果对象，麻将游戏只允许点击或滑动麻将牌，不点击打乱、消除、解锁、使用等游戏功能按钮。

详细版本变化见 `CHANGELOG.md`。
