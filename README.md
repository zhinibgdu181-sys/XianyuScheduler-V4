# XianyuScheduler V4.20

Android Root 闲鱼任务自动执行助手。

## V4.20 重点

- **游戏页面强制分流**：任务标题 OCR 即使把“消”识别成“渭”，点击后只要实际页面是水果/麻将游戏，就进入对应视觉求解器。
- **游戏独占锁**：FruitGameSolver / MahjongGameSolver 工作期间，普通页面恢复、学习经验回放、盲目返回全部暂停。
- **真人学习库降权**：学习模式继续记录真人操作，但自动模式只允许复用“同一外部 App → TASK_PANEL”的边缘返回；必须同 App、同目标页面、同手势类别且累计至少 3 次。TAP、普通滑动和跨 App 经验永不自动回放。
- **极速启动导航**：首页 → 我的 → 闲鱼币 → 赚骰子采用 OCR 单帧接力；用于确认页面的 OCR 直接用于点击下一入口，不再重复截图确认。
- **赚骰子 OCR 容错**：兼容“赚股子 / 赚酸子 / 赚般子 / 赚骰字”等常见识别错误。
- 保留 V4.18 水果视觉求解和 V4.19 麻将视觉求解。

## 学习模式

学习模式仍为 observation-only：只观察真人触摸、页面前后状态和手势，不自动点击或滑动。
学习库继续使用 `xianyu_learning_v413`，覆盖安装不会清除已有学习数据。
