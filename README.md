# XianyuScheduler V4.16

Android Root 闲鱼定时任务助手。

## V4.16：任务面板立即连贯执行

本版针对 V4.15 真机体验继续优化：**只要已经回到“得骰子赚闲鱼币”任务面板，就立即处理下一条可见任务，不再因为上一条任务的进度文字尚未刷新而额外停留。**

核心变化：

- 条件返回/学习返回一旦确认 `TASK_PANEL`，下一轮扫描直接复用这张 OCR 帧，不重复截图。
- 普通任务回到任务面板后只做一次即时验证；若进度尚未刷新，记录为未验证，但**不等待，直接继续下一任务**。
- `签到`、`领取奖励` 仍为最高优先级，进入任务面板后优先马上点击。
- 领取/签到后的 UI 稳定等待缩短为约 120–240 ms。
- 任务间衔接仅保留约 20–90 ms 的页面稳定窗口。
- 外部 App 返回任务面板后的额外等待缩短为约 20–70 ms。
- 明确写有 `15秒`、`30s`、视频、浏览等任务自身所需停留时间保持不变；只压缩**返回任务页后的空等时间**。
- V4.13 学习库、V4.14 真人返回经验、V4.15 自适应任务内等待和人工接管硬停止全部保留。
