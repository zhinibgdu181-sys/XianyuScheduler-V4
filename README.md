# XianyuScheduler V4.5

Android Root 闲鱼定时任务助手。

## V4.5 重点

- AlarmManager → 前台 Service → TaskExecutor 单一执行链。
- KernelSU/Magisk Root Shell + UIAutomator。
- UC WebView 页面新增中文 OCR 兜底。
- 导航状态恢复：未知内嵌页先返回，避免坐标误点。
- OCR 识别任务列表中的“签到 / 领取奖励 / 去完成”。
- “发布”及无法确认标题的任务默认跳过。
- 新增清空日志。
- 以 1440×3120 真机截图校正导航比例坐标，但代码仍按屏幕比例计算，不锁死分辨率。

## 构建

GitHub Actions 会在 push 到 `main` 后执行 Debug APK 构建。

## V4.6 修复摘要

- 保留 V4.5 的截图 OCR 导航与“清空日志”。
- Samsung 桌面/系统 UI 短暂抢前台时先重试，不再直接把整次任务判定为用户中止。
- 停止动作统一为“切回闲鱼定时助手”；外部 App 跳转不再自动等同于中止。
- 任务执行按优先级处理：签到/领取奖励 → 视频与内部浏览 → 外部跳转任务。
- “发布/下载/安装”类任务默认跳过，避免自动产生内容或安装软件。
- 对视频、指定频道、浏览类任务增加有限次数的重复执行上限，避免死循环。
- 内部浏览任务增加定时滑动，任务完成后回到闲鱼重新扫描。
