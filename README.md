# V4.41.0 稳定栈式二消版

本版不继续叠加 V4.40 的激进性能优化，而是回到已经实机证明能够识别并完成一次二消的稳定视觉链路。

水果小游戏规则按三槽 LIFO 栈处理：只允许当前 TOP 与棋盘同类直接二消；0/1 槽没有现成对子时，可进行一次带明确后手的安全压栈；2/3 槽禁止单水果冒险。每次点击后必须重新截图确认槽位状态。

V4.40 的 ROI 像素数组优化已撤销，因为它在首帧检测阶段可复现 `ArrayIndexOutOfBoundsException`，导致游戏实际上没有开始点击。

# XianyuScheduler

当前版本：**V4.41.0**

Android ROOT 辅助自动任务工具。当前界面按功能划分为四个底部入口：

- **首页**：ROOT / 闹钟权限、运行状态、功能说明。
- **今日**：查看当天已经验证完成的闲鱼任务。
- **自动化**：立即运行、停止、每日定时、真人学习模式。
- **日志**：查看并清理运行日志。

小游戏策略采用对象白名单：水果游戏只允许点击水果对象，麻将游戏只允许点击或滑动麻将牌，不点击打乱、消除、解锁、使用等游戏功能按钮。

详细版本变化见 `CHANGELOG.md`。
