XianyuScheduler V4.14

- Reads the existing xianyu_learning_v413 SharedPreferences library.
- Adds conservative learned decision replay for external-app return paths.
- Only EDGE_BACK_RIGHT/EDGE_BACK_LEFT -> TASK_PANEL cases can be replayed automatically.
- Exact-app demonstrated transitions may be used after one verified sample; generalized cases require count >= 2.
- Rejects abnormal learned gesture durations outside 80-1000 ms.
- Every learned gesture is followed by foreground + OCR/XML TASK_PANEL verification.
- Never chains a blind second Back; failed verification falls back to the existing recovery path.
- UNKNOWN_XIANYU and learned TAP cases are not auto-replayed.
- Manual takeover remains a global hard stop.
